Dumphone Recipe

Components:

  • SIM7600X 4G HAT
  • HDMI Miniature Display
  • Rapberry Pi Zero 2 W
  • 5V portable power supply

TUI

TUI is completely driven by raw strings and ANSII Escape codes to control full terminal screen layout. The motivation for handrolling this (ass opposed to using a library like ncurses) is to become more familiar with the low-level Unix system interactions. For example, at various times, Unix system flags must be set to switch the terminal back and forth between raw and canonical modes, depending on whether the program needs to respond instantly to a keypress, or allow the user to edit a line of input before they enter it. Buffering must be carefully managed too: for example, by using `os.fdopen` to access STDIN's file descriptor with buffering disabled (again, allowing instant keystroke responses), or by setting PYTHONUNBUFFERED as an environment variable before launching the TUI to disable output buffering so the terminal responds instantly to escape code commands.
